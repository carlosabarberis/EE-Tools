# EE Tools Launcher

A collection of engineering calculators and design tools by Carlos Barberis.

- **Voltage Scaler** — Scales and converts voltage levels between reference ranges.
- **RLC Resonance Calculator** — Computes resonant frequency and related parameters for RLC circuits.
- **Resistor / Divider Tool** — Calculates voltage divider ratios and resistor values.
- **Capacitor Selector** — Helps select capacitor values and types for a given application.
- **Linear Equation Solver** — Solves systems of linear equations.
- **Air-Flow Cooling Calculator** — Estimates airflow requirements for cooling applications.
- **IIR-Digital Filter Calculator** — Designs IIR digital filter coefficients.
- **Coupling & Snubber Calculator** — Calculates coupling and snubber component values for switching circuits.
- **Heat-Sink Thermal Calculator** — Computes heat-sink sizing and thermal resistance.
- **PWM & Pulse Calculator** — Calculates PWM duty cycle, frequency, and pulse timing parameters.
- **Transistor Amplifier Design** — Assists with biasing and component selection for transistor amplifier stages.
- **SMPS Power Designer Calculator** — Designs switch-mode power supply parameters and components.
- **RC & Constant Current Timing Calculator** — Calculates RC and constant-current timing circuit values.
- **FlyBack Circuit Design** — Designs flyback converter transformer and circuit parameters.
- **FlyBack RCD Snubber Design** — Calculates RCD snubber values for flyback converters.
- **RC Snubber Calculator** — Calculates RC snubber component values for switching circuits.
- **Op-Amp Capacitive Load Design Calculator** — Designs compensation for op-amps driving capacitive loads.
- **RC-LC-RL Circuit Frequency Response Calculator** — Computes frequency response for RC, LC, and RL circuits.
- **Passive LC Filter Design Calculator** — Designs passive LC filter component values.
- **RCD Snubber Calculator** — Calculates RCD snubber component values.
- **Logic Minimizer Calculator** — Minimizes boolean logic expressions.
- **Logic Visualizer Calculator** — Visualizes logic circuits and truth tables.
