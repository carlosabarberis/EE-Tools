## Applications

- **Voltage Scaler Calculator**: op-amp and resistor-divider scaling solver. It picks the circuit topology, solves resistors to E96/E192 values, draws the schematic and plots linearity. [Details](VoltageScaler/README.md)
- **EE Tools Launcher**: a collection of engineering calculators and design tools, including RLC, filters, snubbers, SMPS, flyback, heat sinks and more. [Details](EE_Tools_Launcher_README.md)
- **Bode Viewer**: clean Bode plots from Rigol scope CSV exports, with multi-trace overlay, A/B cursors, and automatic −3 dB bandwidth, Q, phase margin and gain margin. [Details](Bode-Viewer/README.md)
- **STM32 Configurator Toolkit**: timer, PWM, ADC, DMA and NVIC calculator for STM32 that generates CubeMX settings and HAL C code. [Details](STM32-Configurator-Toolkit/README.md)
